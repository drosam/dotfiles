# Grill Me Contract

- Intent: resolve user-owned design decisions before action.
- Shape: inline dependency-aware rounds; no external skill/tool dependency required.
- Inputs: plan plus codebase facts. Output: settled decisions, explicit assumptions/risks, proposed handoff.
- Change: independent questions may share a round; dependent questions wait. Honor one-at-a-time preference.
- Boundaries: discover facts locally; blocked tools remain blocked; never infer implementation approval from interview completion.
- Acceptance: recommendations accompany questions; no unresolved prerequisite is assumed; stop on completion or user request.
- Evidence/limitations: upstream grilling pattern recorded in SOURCES.md; static review does not measure interview quality.
